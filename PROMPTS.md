# Prompts used

Tool: **Claude** (Anthropic), in the Claude app, acting as a coding assistant with access
to a sandbox to write files and run the tests.

The conversation was in Portuguese; original text followed by an English translation.

---

### 1. Initial request

> **Original:** "Aqui está o que me foi solicitado, preciso de ajuda pra criar esse projeto do
> zero, consegue me ajudar?" — followed by the full assignment text (objective, functional and
> non-functional requirements, constraints and deliverables), pasted verbatim.

> **Translation:** "Here is what I was asked to do. I need help creating this project from
> scratch, can you help me?" + the assignment.

### 2. Where to create the project

> **Original:** "Espera, não seria melhor criar numa pasta local, pra eu testar no VS Code?"

> **Translation:** "Wait, wouldn't it be better to create it in a local folder, so I can test it
> in VS Code?"
